# Silver ステップ

Java Silver（1Z0-825-JPN / Java SE 17 Programmer I）合格のための、自分専用の問題集アプリです。
「1問だけ」から始められて、できたことを積み上げていけるように作っています。

`index.html` の1ファイルだけで動きます。ビルドやインストールは不要です。

## 使い方

- ブラウザで `index.html` を開く
- GitHub Pages を有効にすると `https://issei-cloud.github.io/silver-step/` で開けます（スマホのホーム画面にも追加できます）

## 主な機能

| 機能 | 内容 |
|---|---|
| 今日の1問 | ホームからワンタップで1問だけ解ける |
| 学習モード | ヒント、「答えを見てから解く」、1問ごとの解説、「もっと簡単に」 |
| テストモード | ヒントなしで数問解き、最後にまとめて結果と解説を見る |
| 本番モード | 60問・90分・合格ライン65%（ハーフ：30問・45分）。見直しマーク、問題一覧、中断と再開、時間切れで自動採点 |
| 発見ノート | つまずいた問題が集まる。もう一度クリアすると「克服」として卒業 |
| 記録 | 直近14日の積み上げグラフ、章ごとのクリア数、本番モードの成績、バッジ |
| ゲーム要素 | 経験値、レベルと称号、毎日のミッション、連続学習日数 |
| 今日のふりかえり | その日にできたことだけを並べる |

## 問題の追加方法

`index.html` の中にある `QUESTIONS` の配列に、1問ずつ書き足します。書き方はファイル内のコメントにまとめてあります。

```js
{id:'c3-4', ch:3, lv:2, tag:'短い見出し',
 q:'問題文', code:`コード`,
 opts:['選択肢A','選択肢B','選択肢C','選択肢D'],
 ans:0,             // 正解の番号（0から）。2つ選ぶ問題は [0, 2] のように配列で
 hint:'ヒント', one:'ひとことで言うと', flow:['手順1','手順2'],
 easy:'もっと簡単に言うと', words:[['用語','説明']], tip:'コツ'}
```

- `ch`：章（1〜7）、`lv`：1=やさしい、2=ふつう、3=本番レベル
- `hint`・`easy`・`words` は省略できます（省略すると、そのボタンが出なくなります）
- 問題を追加したら、Java で実際に動かして答えを確かめてから入れるのがおすすめです

`BANK` の配列には、これまでのドリルから取り込んだ問題（いずれも Java で実行して確認済み）が入っています。

## 記録の保存先

- Claude のアプリから開いた場合：アカウントに保存され、スマホとPCで共有されます
- それ以外（GitHub Pages やファイルを直接開いた場合）：その端末のブラウザにだけ保存されます
